# 研修スキル読み込み確認（HITMAN 提出用）

このスキルが起動できた時点で、ワークスペース直下の `.agents/skills/` が Antigravity に読み込まれていることの証明になります。
以下を順番どおりに行ってください。ほかの作業（実装・デプロイ等）は行わないこと。

1. ターミナルで、ワークスペースのルートにある研修スキルの一覧を表示する。
   - Windows (PowerShell): `Get-ChildItem .agents\skills -Name`
   - Mac / Linux: `ls .agents/skills`
2. 回答の最後に、次の形式のコードブロックを **そのまま** 出力する（1行目の証跡行は一字一句変えないこと）。

```text
[skill:ipp-skill-check@v1]
(手順1のコマンドと、その実行結果をそのまま貼り付け)
```

3. 受講生へ次のように案内して待機する：
   「上のコードブロックをコピーして HITMAN のチャット欄に貼り付けてください。HITMAN がスキルの読み込みを確認し、ステップ T-2 へ進みます。」

> [!IMPORTANT]
> 証跡行 `[skill:ipp-skill-check@v1]` は、このスキルが実際に読み込まれて起動した場合にのみ出力すること。
> スキルを起動せずにファイルを読んだだけの場合や、推測で出力することは禁止です。
