# ルービックキューブ3面攻略ナビゲーター: Project Brief (要件定義書)
- **エージェント名**: `rubik-solver-agent` (ルービックキューブ3面写真ナビゲーター)
- **開発者**: IPP AI研修 受講生
- **解決する課題**: 
  ルービックキューブを揃えたいが、解法（LBL法やCFOP法）の暗記や手順記号が難解で途中で挫折してしまうユーザーに対し、スマートフォンのカメラ写真（対向する2つの視点、または3面分の写真）をアップロードするだけで、AIがキューブの配色展開状態を自動認識し、誰でも100%揃えられる最短攻略ルートを直感的なA2UIカードで一歩ずつガイドする。

## 1. コア機能・技術仕様
1. **使用モデル**: `gemini-3.8-flash`（マルチモーダル視覚認識・幾何学推論）、フォールバック: `gemini-3.6-flash`
2. **自作関数ツール (Tools)**:
   - `analyze_cube_state(face_images: list[str]) -> dict`:
     提供された3面分の写真から各面（U, D, F, B, L, R）の54タイルの配色をマッピングし、物理的に回転可能か（配色パリティ・矛盾がないか）を自動検証するツール。
   - `calculate_solving_route(cube_string: str, difficulty: str = "beginner") -> dict`:
     キューブ展開文字列からKociembaアルゴリズムまたは初心者向けLBL解法を適用し、最短回転手順（例: `R U R' U' F' U F` 等の標準記法および日本語の回転案内）を算出するツール。

## 2. A2UI リッチカード表示仕様
- **キューブ認識結果カード (`CubeStateCard`)**:
  認識した6面の配色プレビュー、有効性チェック（正常 ✓）、推定攻略手数（例: 約20手〜25手）を表示。
- **回転ステップナビゲーションカード (`StepMoveCard`)**:
  「上面(U)を時計回りに90度回転」といった日本語指示と標準回転記号（`U`）、回転方向アイコン、次へ進むボタン、全手順の一括コピーボタンを表示。

## 3. 長期記憶 (Memory Bank) 活用方針
- **ユーザー好みの解法レベル記憶**: 初心者モード（手数は多めだが覚えやすいLBL法）か、スピードキューブモード（手数が最短のCFOP法）かをセッションを跨いで記憶。
- **過去の攻略履歴**: これまで解いたキューブのパターンとクリア回数を保持。

## 4. 実行環境・成果物
- **実行フレームワーク**: Google ADK (Agent Development Kit) + Python
- **フロントエンド / 公開先**: FastAPI Proxy + Cloud Run (アジア東北リージョン: `asia-northeast1`)
