# カレンダー日記アシスタント: Project Brief

## 1. 基本情報
- エージェント名: calendar_journal_agent
- 表示名: カレンダー日記アシスタント
- 利用者: 自分と家族
- 解決する課題: 予定・タスク・日記がバラバラのアプリに散らばって、週の振り返りができない

## 2. 機能一覧
- F1: 予定の登録と月表示 ／ 受け入れ条件: 日付とタイトルを入力して登録すると、月カレンダーのその日に表示される
- F2: タスクの進捗管理とガント表示 ／ 受け入れ条件: 開始日・終了日・進捗率を持つタスクが横棒で表示される
- F3: 日記の記録とAI週次振り返り ／ 受け入れ条件: 1週間分の日記と予定からAIが振り返りを要約する

## 3. 画面
- S1: 月カレンダー ／ 要素: 月表示、日付クリックで予定入力フォーム ／ 使う機能: F1
- S2: ガント ／ 要素: タスク追加フォーム、進捗率スライダー、横棒チャート ／ 使う機能: F2
- S3: 日記とAIチャット ／ 要素: 日記入力欄、振り返りボタン、チャット欄 ／ 使う機能: F3

## 4. 関数ツール
- add_event(date: str, title: str) -> dict ／ 役割: 予定を保存する ／ 使う機能: F1
- upsert_task(name: str, start: str, end: str, progress: int) -> dict ／ 役割: タスクを保存し進捗を更新する ／ 使う機能: F2
- summarize_week(week_start: str) -> dict ／ 役割: その週の予定・タスク・日記を集めて返す ／ 使う機能: F3

## 5. データと保存先
- 予定・タスク・日記 ／ 保存先: SQLite（ローカル）。Cloud Run では再起動で消える前提（研修の範囲）
